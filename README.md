# Bet on Green

App del gato negro que elige picks de fútbol con probabilidades estadísticas (La Liga, Premier, MLS, Bundesliga y Liga MX).

**Abrir la app:** https://betongreen-us.github.io/betongreen/

Para instalarla en el iPhone: ábrela en Safari → compartir → "Agregar a pantalla de inicio".

Probabilidades estadísticas, no garantías. Juega con responsabilidad.
